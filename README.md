# Hey, I'm Ammar  
### aka Kyssta

I build software that is meant to be useful first and polished second.

Most of my work sits somewhere between web apps, backend systems, automation, infrastructure, and random experiments that turn into real projects. I like building things end-to-end: the frontend, the backend, the deployment, the scaling problems, and sometimes the messy fixes nobody sees.

I’m not locked into one stack. I usually pick whatever gets the job done properly.

## How I like to build

I prefer simple systems over over-engineered ones.

Clean UI, fast backend, understandable code, and a setup that does not break the moment someone touches it.

I care about making things feel solid, not just making them look good in a screenshot.
